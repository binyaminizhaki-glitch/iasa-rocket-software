# IASA Rocket Club | Software

צוות התוכנה של מועדון הרקטאות של יאס״א.

כאן מפתחים ולומדים יחד: תכנות, ניתוח נתונים, סימולציות וכלי בדיקה. מתחילים בפרויקטים קטנים שאפשר להריץ, להבין ולבדוק.

## תחומי העבודה

| תחום | במה עוסקים |
| --- | --- |
| Data & Analysis | קריאת נתונים, קובצי CSV וגרפים |
| Simulation | מודלים וסימולציות לימודיות |
| Embedded Systems | היכרות עם חיישנים ומחשבים משובצים |
| Testing | בדיקות, תיעוד ועבודה משותפת |

## התחלה מהירה

נדרש Python 3.10 ומעלה. אין צורך להתקין ספריות נוספות.

```bash
python -m src.sensor_demo
python -m unittest discover -s tests -v
```

הפקודה הראשונה שומרת נתוני חיישן **מדומים בלבד** בתיקייה `output/`. הפקודה השנייה מריצה את הבדיקות.

## מבנה המאגר

```text
src/         קוד מקור
tests/       בדיקות
README.md    מידע והוראות
.gitignore   קבצים שלא שומרים ב-Git
```

## איך עובדים כצוות?

1. בוחרים משימה קטנה ב-GitHub Issues.
2. עובדים על ענף (Branch) נפרד למשימה.
3. פותחים Pull Request עם הסבר קצר ומבקשים בדיקה של חבר צוות.
4. ממזגים ל-`main` רק אחרי שהקוד עובד ונבדק.

מוסיפים תיקיות וכלים חדשים רק כשצריך אותם.
